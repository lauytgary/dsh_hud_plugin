# docs assets

Images in this folder are embedded in the READMEs (`README.md`, Simplified
Chinese and the default page, and `README-EN.md`, English):

- `social-preview.png` — hero banner shown at the very top of both READMEs
- `screenshot.png` / `mouse_over.png` / `mini.png` — full-panel, hover-tooltip
  and mini-tier captures, shown inline in the READMEs
- `plugin_eng.png` / `plugin_chi.png` — the **Plugins** page with
  `dsh-stats-hud` installed and switched on (English / Chinese UI), captured on
  DSH 0.2.1-rc.5
- `plugin_install_eng.png` / `plugin_install_chi.png` — the **Add plugin**
  dialog with this plugin's GitHub address filled in and **Install** ready
  (English / Chinese UI), captured on DSH 0.2.1-rc.5

Quick way to capture on macOS: press `Shift+Cmd+4`, drag over the target area,
then save the file into this folder (to update an existing capture, replace the
file and keep the same name — the READMEs reference these exact paths).
