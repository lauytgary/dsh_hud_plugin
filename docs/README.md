# docs assets

Images in this folder are embedded in the READMEs (`README.md` /
`README-CN.md`):

- `social-preview.png` — hero banner shown at the very top of both READMEs
- `screenshot.png` / `mouse_over.png` / `mini.png` — full-panel, hover-tooltip
  and mini-tier captures, shown inline in the READMEs
- `plugin_eng.png` / `plugin_chi.png` — the Settings → Plugins list screenshot
  (English / Chinese UI)

Quick way to capture on macOS: press `Shift+Cmd+4`, drag over the target area,
then save the file into this folder (to update an existing capture, replace the
file and keep the same name — the READMEs reference these exact paths).
